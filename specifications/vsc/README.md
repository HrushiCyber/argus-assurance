# ARGUS Verifiable System Claims (VSC)

## Purpose

Verifiable System Claims (VSC) define a machine-readable mechanism for making
bounded claims about properties of digital systems.

A VSC connects:

```text
Subject
   ↓
Property
   ↓
Scope
   ↓
Assumptions
   ↓
Evidence
   ↓
Validation
   ↓
Proof Obligations
   ↓
Claim
   ↓
Independent Verification
   ↓
Verification Result
